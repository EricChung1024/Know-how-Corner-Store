小橘怎麼判斷？（Gemini 依資料分三類，資料不足另列）

A　SOP 有寫

照 SOP 與資深確認過的案例回答，附出處與條號標籤：直接回答／已確認的變更／舊規已失效／暫時規則已過期；紅線規則一定提醒不能違反

B　客服相關
SOP 沒有

先說「SOP 裡沒有寫這題」，再給 2～4 點一般客服建議標示「非 SOP 內容，僅供參考」；不編公司的天數、金額、政策；建議問資深

C　與客服無關

直接回「不在 SOP 範圍」，不回答內容例如天氣、寫程式；要求忽略規則的問題一律當 C

資料不足

「新舊版都不符 → 請問資深」，寫入待確認清單資料有相關但不足以確定答案時才使用

程式把關：不單靠模型的說法

  • 沒給來源的「有答案」→ 重問一次，仍沒有就改「不在範圍」
  • 客服字眼（客人、退款、個資…）卻被判無關 → 重問
  • 延伸回答只有固定句、沒建議 → 重問
  • 引用的規則不是紅線卻說紅線 → 刪掉那句
  • 出處、條號由引用的片段推出，不信任模型自己寫的

出問題時：自動退回，網站不會壞
